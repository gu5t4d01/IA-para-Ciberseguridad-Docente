# IA para Ciberseguridad - Maestría en Analítica de Datos

**Autor:** Gustavo Gómez | Especialista en Ciberseguridad
**Año:** 2026

Este repositorio contiene el ecosistema técnico diseñado para la electiva de profundización en la Maestría en Analítica de Datos. El enfoque principal es cerrar la brecha entre el científico de datos y el profesional de seguridad.

## Objetivo General del Curso

Aplicar modelos de inteligencia artificial y machine learning sobre datos reales de entornos de ciberseguridad para detectar amenazas, analizar comportamientos anómalos y apoyar la toma de decisiones en equipos de seguridad corporativa, dentro del marco normativo colombiano vigente.

## Ruta de Aprendizaje

El curso se organiza en 40 horas totales de dedicación, distribuidas en 7 unidades temáticas:

1. El Paisaje de Amenazas Moderno.
2. Datos de Seguridad: Fuentes y Estructura.
3. Machine Learning Aplicado a Detección de Amenazas.
4. Identidad, Acceso y Comportamiento de Usuarios (UEBA).
5. Inteligencia Artificial en la Nube y Protección de Datos.
6. Adversarial AI y Limitaciones de los Modelos.
7. Ética, Normatividad y Decisiones con IA.

## Stack Tecnológico

* Lenguaje: Python 3.x
* Librerías: pandas, numpy, scikit-learn, matplotlib, seaborn
* Entorno: Google Colab / Jupyter Notebooks
* Datasets de referencia: CERT Insider Threat r4.2, NSL-KDD

## Marco Normativo

El contenido y las actividades prácticas se alinean con la regulación colombiana:
* Ley 1581 de 2012 (Protección de Datos Personales).
* CONPES 3995 (Política Nacional de Confianza y Seguridad Digital).
